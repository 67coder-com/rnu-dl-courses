▸Course Project 1✓✓ id 3333 CP / 6 CPОбъём не совпадает

В чём проблема

  • Объём: в силлабусе 3 CP (75 ак. ч., из них 32 контактных), в таблице руководителя 6 CP.
  • Семестры: в таблице курс разбит на 2 семестра (2-й — 3 CP, 4-й — 3 CP), а в Moodle это один курс.
  • Похоже на причину: в силлабусе Course Project 1 — 3 CP, Course Project 2 — 3 CP, Course Project 3 — 6 CP; в таблице курсовые сгруппированы иначе.

Возможное решение

  • В таблице курсовой на 6 CP = 3 CP в 2-м семестре + 3 CP в 4-м семестре: по силлабусам это два отдельных курсовых — Course Project 1 (3 CP) и Course Project 2 (3 CP), каждый своим курсом в Moodle.
  • Если в плане нужен курсовой на 6 CP — по объёму подходит Course Project 3 из силлабусов.
  • Или привести таблицу к силлабусу: Course Project 1 — 3 CP.
  • Силлабус один — оставить один курс в Moodle на оба семестра (рекомендуем); или разделить курс в Moodle на две части по семестрам.
